# KEMET — THE SIX CRYSTALS
## Your Future Quest · Six Crystals. Six Questions. One Future to Build.

**Stage:** GitHub handoff prepared; **original PNGs and illustrated documentation are not uploaded to this branch yet**.

**Experience:** Nine original portrait images shown **sequentially** within the existing KEMET — The Nile Flow app. This is a **static card sequence, not a coded interactive game**.

### Concept
“Check Your Crystals” is a brief, cinematic Egyptian-inspired motivational and educational storytelling sequence for secondary-school students. Each symbolic card invites reflection on changing circumstances, personal agency, pride in Egyptian cultural achievement, future aspirations, planning, sustained effort and confidence. At the end, learners choose the message that resonated with them and reflect on one realistic action. The “crystals” are symbolic prompts for reflection, **not tools for predicting the future**.
